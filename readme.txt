A clean, multipurpose WordPress block theme for business, agency and SaaS sites — a Gutenberg full site editing (FSE) theme built entirely from core blocks, no page builder required.
 
== Description ==

bBlocks is a lightweight, multipurpose full-site-editing (FSE) block theme built for businesses, agencies, SaaS products, freelancers, portfolios and blogs. Rather than shipping a one-click demo import, bBlocks gives you a coherent design system and a library of over 25 ready-to-use block patterns — hero, about, features, services, team, testimonials, pricing, call-to-action, contact and blog sections — that snap together in the Site Editor to assemble the site you actually need.

Every pattern, template and template part in bBlocks is built entirely from WordPress core blocks. There is no page builder, no bundled plugin, and no external service required for the theme to work correctly. An optional companion bBlocks plugin is planned for a future release to add a small number of extra blocks; it will never be required to install, activate or use this theme, and version 1.0 does not depend on it in any way.

The theme includes three header styles (logo with navigation; logo with navigation and a call-to-action button; and a centered logo with navigation) and three footer styles (a simple single-row footer; a three-column footer; and a four-column footer with social links), all available as swappable template parts in the Site Editor. Three global style variations are included: the Default light theme, "Modern" (a violet-and-emerald re-skin), and "Dark" (a dark re-skin) — switchable with one click from the Styles panel, with no page rebuilding required.

bBlocks ships seven templates covering every part of a typical site — a homepage/blog index, a generic page template used for every page you create, a single post template, an archive template for categories and tags, a search results template, and a 404 page — plus the pattern library described above. Combine the patterns on the "page" template to put together a Business site (Home, About, Services, Contact, Blog), an Agency site (Home, About, Services, Portfolio, Contact) or a SaaS landing page (Home, Features, Pricing, About, Contact); every layout in this description is assembled from the same set of patterns, with no separate demo-import system needed.

bBlocks includes basic compatibility with WooCommerce: if WooCommerce is active, product galleries and core shop, cart, and checkout pages will display using WooCommerce's own block templates without breaking your layout. This is not a full custom WooCommerce design system — it simply ensures the theme won't get in WooCommerce's way.

= Key features =

* Over 25 block patterns across ten categories: hero, about, features, services, team, testimonials, pricing, call-to-action, contact and blog.
* Three header styles and three footer styles, all editable template parts.
* Three style variations: Default, Modern and Dark — switch instantly from the Styles panel.
* Seven core templates: homepage/blog index, page, single post, archive, search, and 404.
* Built entirely from WordPress core blocks — no page builder or bundled plugin required to render or edit the site.
* A named design system exposed through Global Styles: Primary, Secondary, Accent, Text, Muted Text, Background, Surface and Border colors; Small, Medium, Large and Extra Large spacing; and a full typography scale from Body text through Heading 1–6.
* Optional companion bBlocks plugin support planned for a future release — never required for this theme to work.
* Basic WooCommerce compatibility (product gallery support; no custom WooCommerce template overrides).
* Self-hosted variable font (no external font requests), fluid typography, and a wide/contained layout system (1200px max content width).
* Translation ready, with a text domain used consistently throughout.
* Accessibility-conscious: visible focus states, semantic headings, sufficient color contrast in all three style variations, and reduced-motion support.
* Responsive by default across phone, tablet and desktop breakpoints.

= A note on the optional bBlocks plugin =

bBlocks the theme and bBlocks the plugin (planned) are separate products. Version 1.0 of this theme uses core WordPress blocks exclusively and does not include or require the plugin in any way. A small number of plugin-specific patterns may be added in a future theme update, and they will be clearly marked and will degrade gracefully — meaning your site will continue to work normally — if the plugin isn't installed.

== Installation ==

= From within WordPress =

1. Go to Appearance → Themes → Add New.
2. Search for "bBlocks".
3. Click Install, then click Activate.

= Uploading in WordPress =

1. Go to Appearance → Themes → Add New → Upload Theme.
2. Upload the bblocks.zip file.
3. Click Install Now, then click Activate.

= Building your site =

1. In the Site Editor, open Styles and choose the Default, Modern or Dark style variation.
2. Open the Header and Footer template parts and choose the header/footer style you prefer, then update the logo, navigation menu and contact details.
3. Create a new page, choose the patterns you need from the pattern inserter (hero, about, features, services, team, testimonials, pricing, call-to-action, contact, blog), and arrange them in the order that fits your site — Business, Agency and SaaS layouts are all just different combinations of the same patterns.
4. Publish your posts as usual — the homepage/blog index, single post, archive and search templates will pick them up automatically.

== Frequently Asked Questions ==

= Does this theme require any plugin to work? =

No. Every template, template part and pattern in bBlocks is built entirely from WordPress core blocks. Nothing needs to be installed or activated for the site to render and work correctly.

= Does bBlocks include demo content or a one-click importer? =

No. Version 1.0 is intentionally lean — instead of an importer, it gives you a library of ready-made patterns you assemble yourself directly in the Site Editor, using the Business, Agency and SaaS examples in the description above as a starting point.

= Is the bBlocks plugin required? =

No, and it never will be for this theme to function. The plugin is a separate, optional product. It does not exist as of this release; a small set of plugin-aware patterns may be added in a future version, always with graceful fallback if the plugin is inactive.

= Is this theme compatible with WooCommerce? =

bBlocks includes basic WooCommerce support (product gallery features) so standard shop, product, cart and checkout pages display correctly using WooCommerce's own templates. It does not include a custom-designed WooCommerce experience.

= Can I change the colors, fonts and spacing? =

Yes. Open the Site Editor and go to Styles to adjust colors, typography and layout, or switch between the three bundled style variations (Default, Modern, Dark) for a one-click re-skin.

= Where do I report bugs or request features? =

Please use the theme's support forum on WordPress.org.
