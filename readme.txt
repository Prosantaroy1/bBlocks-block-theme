Multipurpose block theme with 9 starter sites, 76 patterns and 8 styles for business, agency, SaaS, portfolio and blog sites. No page builder needed.
 
== Description ==
bBlocks is a lightweight, multipurpose full-site-editing (FSE) block theme built for businesses, agencies, SaaS products, freelancers, portfolios and blogs. bBlocks gives you a coherent design system and a library of 76 ready-to-use block patterns in seventeen categories — hero, about, features, services, team, testimonials, pricing, call-to-action, contact, blog, FAQ and portfolio sections — that snap together in the Site Editor to assemble the site you actually need.

Every pattern, template and template part in bBlocks is built entirely from WordPress core blocks. There is no page builder, no bundled plugin, and no external service required for the theme to work correctly. The free companion bBlocks plugin adds extra blocks if you want them; it is never required to install, activate or use this theme.

The theme dashboard (Appearance → bBlocks) brings everything together: quick links into the Site Editor, optional modules, nine one-click starter sites and recommended plugins. Starter sites (Business, Creative Agency, SaaS Product, Freelancer, Nirman Architecture, DigiMagnet Marketplace, Naturexplo Eco Resort, Sweet Pixie Spa and Conselta Consulting) build their pages from the theme's own patterns — nothing is downloaded, your posts are never changed and importing again updates the same pages. The optional modules — back to top, dark mode toggle, reading progress bar, smart sticky header, scroll animations, footer reveal and floating contact buttons — are all off by default and load nothing until you switch one on.

The theme includes three header styles (logo with navigation; logo with navigation and a call-to-action button; and a centered logo with navigation) and three footer styles (a simple single-row footer; a three-column footer; and a four-column footer with social links), all available as swappable template parts in the Site Editor. Three global style variations are included: the Default light theme, "Modern" (a violet-and-emerald re-skin), and "Dark" (a dark re-skin) — switchable with one click from the Styles panel, with no page rebuilding required.

bBlocks ships eleven templates covering every part of a typical site — a homepage/blog index, a generic page template, a full-width landing page, a page without title, a page with sidebar, a page with wide image, a single post template, an archive template for categories and tags, a search results template, and a 404 page — plus the pattern library described above. Combine the patterns on the "Landing Page (Full Width)" template to put together a Business site (Home, About, Services, Contact, Blog), an Agency site (Home, About, Services, Portfolio, Contact) or a SaaS landing page (Home, Features, Pricing, About, Contact) — or let a starter site do it for you.

bBlocks includes basic compatibility with WooCommerce: if WooCommerce is active, product galleries and core shop, cart, and checkout pages will display using WooCommerce's own block templates without breaking your layout. This is not a full custom WooCommerce design system — it simply ensures the theme won't get in WooCommerce's way.

= A note on the optional bBlocks plugin =

bBlocks the theme and bBlocks the plugin are separate products. The theme uses core WordPress blocks exclusively and does not include or require the plugin in any way. The dashboard's Recommended Plugins tab can install it from WordPress.org, but only when you click — the theme never installs anything by itself.

== Installation ==

= From within WordPress =

1. Go to Appearance → Themes → Add New.
2. Search for "bBlocks".
3. Click Install, then click Activate.

= Uploading in WordPress =

1. Go to Appearance → Themes → Add New → Upload Theme.
2. Upload the bblocks.zip file.
3. Click Install Now, then click Activate.

= Building your site =

1. In the Site Editor, open Styles and choose the Default, Modern or Dark style variation.
2. Open the Header and Footer template parts and choose the header/footer style you prefer, then update the logo, navigation menu and contact details.
3. Create a new page, choose the patterns you need from the pattern inserter (hero, about, features, services, team, testimonials, pricing, call-to-action, contact, blog, FAQ, portfolio), and arrange them in the order that fits your site — Business, Agency and SaaS layouts are all just different combinations of the same patterns.
4. Publish your posts as usual — the homepage/blog index, single post, archive and search templates will pick them up automatically.

== Frequently Asked Questions ==

= Does this theme require any plugin to work? =

No. Every template, template part and pattern in bBlocks is built entirely from WordPress core blocks. Nothing needs to be installed or activated for the site to render and work correctly.

= Does bBlocks include demo content or a one-click importer? =

Yes. Go to Appearance → bBlocks → Starter Sites and import Business, Creative Agency, SaaS Product or Freelancer. Each one creates its pages from the theme's own patterns, sets your homepage and blog page, and can create a navigation menu and apply the matching style. Nothing is downloaded and your existing posts are never changed; importing again updates the same pages instead of duplicating them.

= Is the bBlocks plugin required? =

No, and it never will be for this theme to function. The plugin is a separate, optional product that adds extra blocks.

= What do the modules do, and do they slow my site down? =

Modules are optional front-end extras (Appearance → bBlocks → Modules). All of them are off by default, and the theme loads no module CSS or JavaScript until at least one is switched on. Animations respect the visitor's reduced-motion setting.

= Is this theme compatible with WooCommerce? =

bBlocks includes basic WooCommerce support (product gallery features) so standard shop, product, cart and checkout pages display correctly using WooCommerce's own templates. It does not include a custom-designed WooCommerce experience.

= Can I change the colors, fonts and spacing? =

Yes. Open the Site Editor and go to Styles to adjust colors, typography and layout, or switch between the three bundled style variations (Default, Modern, Dark) for a one-click re-skin.

= Where do I report bugs or request features? =

Please use the theme's support forum on WordPress.org.
