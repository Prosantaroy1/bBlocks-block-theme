FAQ

Questions, answered

Is bBlocks really free? What's the catch?

Yes. bBlocks is GPL-licensed and every feature — starter sites, patterns, styles, modules and WooCommerce templates — is in the free theme on WordPress.org. There is no Pro version and no licence key.

Does this theme require any plugin to work?

No. Every template, template part and pattern is built entirely from WordPress core blocks. Nothing needs to be installed for the site to render and work correctly. The bBlocks plugin is a separate, optional product that adds extra blocks.

How do starter sites work?

Go to Appearance → bBlocks → Starter Sites and import one. It creates pages from the theme's own patterns, sets your homepage and blog page, and can create a menu and apply the matching style and header. Nothing is downloaded, your existing posts are never changed, and importing again updates the same pages instead of duplicating them.

Do the modules slow my site down?

No. All modules are off by default, and the theme loads no module CSS or JavaScript until at least one is switched on. Animations respect the visitor's reduced-motion setting.

Is bBlocks compatible with WooCommerce?

Yes. bBlocks ships shop, product, search results, cart, checkout and order confirmation templates that follow your chosen style, plus the Modista Fashion and Voltix Electronics starter sites while WooCommerce is active. Without WooCommerce, the Shoplane starter site still gives you a product showcase built from core blocks.

Can I change the colors, fonts and spacing?

Yes. Apply one of the styles from Appearance → bBlocks → Design, or open Styles in the Site Editor to pick a style, a color palette or a font pairing and fine-tune colors, typography and layout.

How do I change the header or footer?

Use Appearance → bBlocks → Design, or select the header in the Site Editor and choose "Replace". Choosing the first design in the Design tab restores the original header or footer.

Is it accessible and translation ready?

Yes. bBlocks uses keyboard-friendly navigation, self-hosted fonts and reduced-motion support, and it is translation and RTL ready with an included .pot file.
