Introduction to bBlocks

bBlocks is a free, fast WordPress block theme that gives small businesses a professional website without a page builder.

What's included

Complete websites — restaurant, clinic, law firm, gym, real estate, agency, store and more — imported in one click.

194 block patterns

22 style variations

Plus 6 color palettes and 5 font pairings you can switch with one click.

23 templates

Blank Canvas, Landing Page, sidebar layouts, cover posts and full WooCommerce templates.

9 optional modules

Dark mode, sticky header, announcement bar, WhatsApp buttons and more — all off by default.

Theme dashboard

A setup checklist, starter site importer and one-click design changes under Appearance → bBlocks.

How bBlocks works

bBlocks is a block theme. Everything you see — headers, footers, templates and sections — is made from the blocks that ship with WordPress, and you edit it visually in the Site Editor (Appearance → Editor).

  • No page builder. There is nothing extra to install, pages stay fast, and your content keeps working if you ever switch themes.
  • No plugin required. Every template, template part and pattern renders with WordPress core alone.
  • No Pro version. Every feature is in the free theme on WordPress.org. There are no licence keys.

New here? Follow the Quick start — most people have a finished site in an afternoon.

bBlocks installs like any theme from the WordPress.org directory.

Install from your dashboard

  1. Open the theme directoryGo to Appearance → Themes → Add New.
  2. Search for bBlocksType “bBlocks” in the search box.
  3. Install and activateClick Install, then Activate.

Upload a zip file

  1. Download the themeGet bblocks.zip from WordPress.org.
  2. Upload itGo to Appearance → Themes → Add New → Upload Theme and choose the file.
  3. ActivateClick Install Now, then Activate.

After activation a short welcome notice appears on the Themes screen with a link to the bBlocks dashboard.

Import a starter site

A starter site is a complete website — home, about, services, pricing, contact and blog pages — built from the theme's own patterns.

Import in one click

  1. Open Starter SitesGo to Appearance → bBlocks → Starter Sites. Use search, categories or the status filter to find a site.
  2. Preview itEvery site can be explored live on the starter sites page before you import.
  3. Choose the options“Also apply the matching style” is checked by default, so colors, fonts and header match the demo. You can also let it create the navigation menu.
  4. ImportClick Import. Your pages, homepage and blog page are set up in a few seconds.

What an import does

  • Creates the site's pages from the bundled patterns, using the Landing Page (full width) template.
  • Sets your homepage and posts page under Settings → Reading.
  • Optionally creates a navigation menu with those pages and applies the matching style and header.

Nothing is downloaded and your existing posts are never changed. Importing the same site again updates the pages it created before instead of making duplicates.

After importing

Open each page and replace the sample text and photos with your own, then update the logo and menu. See Logo, title & menu.

Style variations

A style changes colors, fonts, buttons and spacing across every page, pattern and template at once.

Apply a style from the dashboard

  1. Open DesignGo to Appearance → bBlocks → Design.
  2. Pick a styleClick Apply on any style — Default, Modern, Dark or one of the starter-site styles like Savora, Lumen or Justica.

Apply a style in the Site Editor

Open Appearance → Editor → Styles, browse the style variations and save. From the same panel you can fine-tune individual colors, typography and layout.

Styles only change design settings. Your content and pages stay exactly as they are, so you can try as many as you like.

Colors & typography

Colors, fonts and spacing are defined once in theme.json, so every section stays consistent.

Color palettes

Six palettes are included: Forest, Midnight, Monochrome, Ocean, Rose and Sunset. Choose one under Styles → Colors → Palette in the Site Editor.

Font pairings

Five pairings use self-hosted Inter, Manrope, Poppins and Playfair Display — no requests to Google Fonts, which is faster and privacy-friendly. Pick one under Styles → Typography.

Sizes and spacing

Font sizes are fluid and scale smoothly between phone and desktop. Content is 768px wide for reading and 1200px for wide sections; full-width sections run edge to edge.

Change the design

  • From the dashboard: Appearance → bBlocks → Design, then choose a header or footer.
  • In the Site Editor: select the header or footer, open the block toolbar and choose Replace.

Choosing the first design in the Design tab restores the theme's original header or footer.

Logo, title & menu

Add your logo

  1. Open the headerGo to Appearance → Editor → Patterns → Header (or click the header on any page in the editor).
  2. Upload the logoSelect the Site Logo block and upload an image. With “Use as site icon” on, it also becomes the browser tab icon.
  3. Edit the titleClick the Site Title to change it, then save.

Edit the menu

Select the Navigation block in the header to add, remove and reorder links, or manage menus under Appearance → Editor → Navigation. If you imported a starter site with the menu option, its pages are already in the menu.

On phones the menu collapses into a button that opens a full-screen overlay automatically.

Using patterns

Patterns are ready-made sections. Insert one, replace the text and images, and you're done.

Insert a pattern

  1. Open the inserterEdit a page and click the + button at the top left.
  2. Choose PatternsOpen the Patterns tab and pick a bBlocks category — Hero, About, Features, Services, Team, Testimonials, Pricing, Call to Action, Contact, Blog, FAQ, Portfolio or Utility. Each starter site also has its own category.
  3. Click to insertThe section is added where your cursor is. Edit it like any other blocks.

Tips

  • Patterns follow your active style, so they always match the rest of your site.
  • Use the Landing Page (Full Width) template for pages built from full-width sections.
  • Utility patterns include Coming Soon, Maintenance, Newsletter and a 404 section.

Modules are optional front-end extras under Appearance → bBlocks → Modules.

All modules are off by default, and the theme loads no module CSS or JavaScript until at least one is switched on.

Module settings

Floating contact buttons

Fill in a phone number, an email address and/or a WhatsApp number. Only the buttons you fill in are shown.

Announcement bar

Enter the message, and optionally a link and button text (it defaults to “Learn more”). Visitors can dismiss the bar.

Performance & accessibility

Performance

  • Core blocks only — no page builder scripts.
  • Self-hosted fonts, loaded with font-display: swap.
  • Module assets load only when a module is switched on.

Accessibility

  • Keyboard-friendly navigation: submenus open and close with their own toggle button and Escape.
  • Animations respect the visitor's reduced-motion setting.
  • Every pattern button links to a real destination, so all controls work with the keyboard.

Translation & RTL

All text in templates, parts and patterns is translatable, and the theme includes languages/bblocks.pot. Right-to-left languages are supported.

Frequently asked questions

Is bBlocks really free?

Yes. bBlocks is GPL-licensed and every feature is in the free theme on WordPress.org. There is no Pro version and no licence key.

Does the theme require a plugin?

No. Everything is built from WordPress core blocks. The bBlocks plugin is a separate, optional product that adds extra blocks.

Will importing a starter site delete my content?

No. Your existing posts are never changed, and re-importing updates the pages it created before instead of duplicating them.

Do modules slow my site down?

No. They are off by default and load nothing until you switch one on.

Can I change colors, fonts and spacing?

Yes — apply a style from the Design tab, or open Styles in the Site Editor to pick a palette or font pairing and fine-tune everything.

How do I change the header or footer?

Use Appearance → bBlocks → Design, or select it in the Site Editor and choose “Replace”.
