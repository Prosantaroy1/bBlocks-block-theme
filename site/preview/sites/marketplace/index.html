Frequently Asked Questions

How do I install a theme from the marketplace?

Download the theme zip, then go to Appearance → Themes → Add New → Upload Theme in your dashboard and activate it.

Can I customize a theme to match my brand?

Yes. Every theme uses Global Styles, so colors, fonts and spacing can be changed for the whole site in a few clicks.

What kind of support do you provide?

Every purchase includes help with installation, setup questions and bug fixes for the life of the product.

Are the themes compatible with popular page builders?

They are built for the block editor and work with the core blocks — no page builder is required.

Do the themes support online stores?

Yes, they include WooCommerce compatibility so shop, cart and checkout pages display correctly.

Is there a refund policy?

If a theme does not work as described, contact us within 30 days for a full refund.
